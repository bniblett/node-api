# # Getting Started with the Node API Service

This is a bare-bones example of a Sinatra application providing a REST
API to a DataMapper-backed model.

The entire application is contained within the `src/` directory, executed through `src/app.js`.

`tests/run-tests.sh` runs a simplistic test and generates the API
documentation below.

## Install

    npm install

## Run the app locally

    npm run dev

## Run the tests

    ** REPLACE **

## Build the docs locally

    npm run docs
